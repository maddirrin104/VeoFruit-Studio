# Background Music

Put your default background music file here as `default.mp3`.

The app will use:
- `BACKGROUND_MUSIC_PATH` from `.env` if it is set
- otherwise `public/bg-music/default.mp3`

Recommended:
- keep the music low-volume and loop-friendly
- use MP3 for best compatibility
- choose a calm, clean track so it does not fight with the voice-over
